Funcionalidades da Página Web

Página Inicial (index.html)
Apresenta uma visão geral do petshop, com informações sobre a loja e links de acesso rápido para as categorias de produtos e serviços. Possui um carrossel com banners animados.
Página de Produtos (produtos.html)
Exibe os produtos organizados em três categorias: Acessórios (roupas, brinquedos, camas), Rações Não Perecíveis (rações secas e úmidas) e Produtos de Higiene e Limpeza (tapetes higiênicos, fraldas). Cada produto contém foto, descrição e valor.
Página de Serviços (servicos.html)
Apresenta os serviços de banho e tosa disponíveis no petshop, com as opções sem tele-busca e com tele-busca. Cada serviço contém descrição detalhada e valor. Possui formulário de agendamento com calendário para seleção de data e horário.
Página de Cadastro (cadastro.html)
Formulário de cadastro de cliente e pet. Contém campos de identificação do cliente (nome, CPF, sexo, telefone, e-mail, endereço) e do pet (nome, raça, idade, espécie, porte). Validação de campos obrigatórios via JavaScript.
Página de Ajuda (ajuda.html)
Esta página. Descreve as funcionalidades de cada página do site e fornece informações de contato e suporte.

Como Navegar pelo Site

  1. No menu de navegação (presente no cabeçalho de todas as páginas), clique na seção desejada.
  2. Para visualizar os produtos, acesse a página Produtos e role para baixo para ver as três categorias.
  3. Para conhecer os serviços de banho e tosa, acesse a página Serviços.
  4. Para se cadastrar, acesse a página Cadastro e preencha o formulário.
  5. Para agendar um serviço, acesse a página Serviços e preencha o formulário de agendamento.
  6. Caso tenha dúvidas, acesse a página Ajuda.

Recursos de Acessibilidade

Este site possui recursos de acessibilidade para deficientes visuais, incluindo:

  • Atributo alt com audiodescrição detalhada em todas as imagens.
  • Link de skip ("Pular para o conteúdo principal") para navegação via teclado.
  • Foco visível em todos os elementos interativos (links, botões, campos de formulário).
  • Atributos aria-label e aria-live em elementos dinâmicos.
